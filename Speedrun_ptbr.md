### Estratégia Speedrun

Nesta estratégia, os testadores jogam o jogo com o objetivo de alcançar uma meta específica o mais rápido possível, muitas vezes contornando elementos padrão de jogabilidade.

```
"Esta estratégia ajuda os testadores a experimentar diferentes caminhos e descobrir possíveis exploits.
Os testadores aprendem sobre os caminhos e objetivos do segmento de teste do jogo, definem novos objetivos e tentam alcançá-los usando o caminho mais curto ou mais rápido disponível.
Eles buscam atingir as metas rapidamente, ignorando requisitos ou tentando caminhos alternativos."
```

### Objetivos

- Use o objetivo do jogo.
    - Algum dos colecionáveis é necessário para vencer a meta ou objetivo do jogo?
    - Existem requisitos obtíveis para vencer a meta ou objetivo do jogo?
    - Entre os caminhos disponíveis, qual é o mais rápido para alcançar a meta do jogo?
    - Qual caminho é o mais curto para alcançar a meta do jogo?
    - Existem tarefas ou missões necessárias para desbloquear caminhos?
    - Existem caminhos necessários para vencer o jogo que estejam bloqueados?
    - É possível vencer o jogo sem derrotar inimigos (ou derrotando o menor número possível)?
    - O jogo exige interações obrigatórias com NPCs?
    - Derrotar inimigos ou interagir com NPCs desbloqueia recompensas ou caminhos adicionais?
- Defina um objetivo de speedrun X que não seja o objetivo atual do jogo.
    - Algum dos colecionáveis é necessário para vencer a sua meta ou objetivo?
    - Existem requisitos obtíveis para vencer a sua meta ou objetivo?
    - Entre os caminhos disponíveis, qual é o mais rápido para alcançar a sua meta?
    - Qual caminho é o mais curto para alcançar a sua meta?
    - Existem tarefas ou missões necessárias para desbloquear caminhos até a sua meta?
    - Existem caminhos necessários para vencer a sua meta que estejam bloqueados?
    - É possível vencer a sua meta sem derrotar inimigos (ou derrotando o menor número possível)?
    - A sua meta exige interações obrigatórias com NPCs?

### Exemplos
